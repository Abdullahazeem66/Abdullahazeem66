## <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="28"> About Me

I'm an **SQA Engineer** with experience across **AI application testing**, **test automation**, and **manual software testing**.

**AI Application Testing**
- Helped explore and establish ways to test AI-powered applications: **chatbots, RAG applications, AI agents, voice agents and AI medical scribes**
- Evaluate **response accuracy, hallucinations, retrieval quality, agent behavior** and **system reliability**
- Tools: **Promptfoo, DeepEval, LangSmith**

**Custom Testing Tools**
- Built a **comprehensive testing tool for AI voice agents**
- Designed an **AI medical scribe testing approach** using synthetic test data and AI evaluations, later turned into a testing utility

**Test Automation**
- Build efficient, maintainable **Playwright** test frameworks and end-to-end automated tests that improve testing speed, coverage and reliability
- Growing in **CI/CD**, with basic exposure to performance testing using **JMeter**

**Manual QA**
- Functional testing, test case design, defect reporting, regression testing and end-to-end validation

**AI in QA Workflows**
- Using AI for requirement analysis, test generation, defect reporting and AI-assisted automation with **Playwright MCP**

Always looking to expand my skills in test automation and AI evaluation, take on new challenges, and build solutions that make software testing more effective.
